# 群唤醒前缀自定义（Group Wake Prefix ）

本插件可通过指令在不同群聊自定义不同唤醒词，解决群聊众多机器人唤醒词重合导致一呼百应的问题。支持在不同群内通过指令**自定义专属唤醒前缀**（符号或词），实现按群区分的唤醒方式；并可**屏蔽/恢复系统内置的命令唤醒**（/ 前缀、平台 wake_prefix），**@ 提及与引用回复不受影响**。

让 AstrBot 在**不同群里支持不同的唤醒符号/词语**。每个群的管理员可以用一条指令把本群的唤醒前缀设成任意字符（比如 A 群用 `#`、B 群用 `~`、C 群用 `小紬`），之后该群消息只要以对应前缀开头，就会唤醒机器人，**并且能像 `/指令` 一样触发其它插件的指令**（如 `#点歌 周杰伦` → 触发点歌插件）。

系统自带的 `wake_prefix`（默认 `/`）是全局统一的，无法按群自定义；本插件补全了这个能力，并额外提供「设了自定义前缀后**屏蔽系统内置命令唤醒**」的开关：`/` 与 `wake_prefix` 触发的指令会被屏蔽，**@ 提及、@全体、引用回复机器人不受影响**，仍可正常唤醒机器人对话。

## 配置项

| 配置项                | 默认       | 说明                                                                                                         |
| ------------------ | -------- | ---------------------------------------------------------------------------------------------------------- |
| `allow_member_set` | false    | 是否允许普通群成员设置本群唤醒前缀。关闭时仅管理员可设置。                                                                              |
| `match_mode`       | `prefix` | `prefix`=消息以该前缀**开头**才唤醒；`contains`=消息任意位置**包含**该前缀即唤醒。                                                    |
| `suppress_builtin` | true     | 本群已设自定义前缀时，是否**屏蔽系统内置命令唤醒**（`/` 前缀、平台 `wake_prefix` 触发的指令）。**`@` 提及、`@全体`、引用回复机器人始终不受影响**。关闭则自定义前缀与内置唤醒并存。 |

## 指令（在群聊内使用）

| 指令                  | 作用                                                   | 权限                             |
| ------------------- | ---------------------------------------------------- | ------------------------------ |
| `/setwake 前缀1 前缀2`  | 新增本群唤醒前缀，支持一次设多个；**多次设置会累积**（不会覆盖之前的唤醒词）                                     | 管理员（或开启 allow_member_set 后所有人） |
| `/delwake`          | 清除本群自定义唤醒前缀                                          | 管理员                            |
| `/wakeprefix`       | 查看本群当前唤醒前缀与系统 wake_prefix                            | 所有人                            |
| `/wakestatus [指令名]` | **诊断**：打印补丁层数、本群前缀、AstrBot 真实 `wake_prefix`、该指令是否已注册 | 管理员                            |
| `/wakereset`        | **强制重置**：清空所有自定义前缀并刷新命令拦截层（解决热重载残留旧层）                | 管理员                            |

> 下表中的 `/` 指你 AstrBot 实际配置的 `wake_prefix`（默认 `/`）。若你把 `wake_prefix` 改成了 `#`，请相应写成 `#setwake`。插件所有回复里的指引都会自动替换成你实际生效的前缀。

示例：

```
/setwake #
/setwake 紬 小紬
/delwake
/wakeprefix
```

设置为#后，群里发 `#你好` 就能唤醒；未设前缀的群仍走系统默认 如`/`。

`/setwake` 是**新增模式**：先 `/setwake a` 再 `/setwake b`，最终本群唤醒词为 a、b，a 不会被清掉；重复设置相同前缀会自动去重。清除请用 `/delwake`（全部清除）。

**自定义前缀能触发其它插件的指令**。例如把本群前缀设成 `#` 后，`#点歌 周杰伦` 会像 `/点歌 周杰伦` 一样唤起点歌插件——插件会在指令匹配前自动把 `#` 剥掉，所以指令处理器能正常识别。同理 `#setwake`、`#delwake`、`#wakeprefix` 也能用自定义前缀执行。

## 工作原理

AstrBot 在 `WakingCheckStage` 阶段完成唤醒判定，依据 `event.is_at_or_wake_command` 决定是否激活指令处理器，且判定结果会固化，普通消息钩子无法修改。因此插件通过 Monkey-Patch 劫持指令统一入口 `CommandFilter.filter` 实现：

1. **自定义前缀触发指令**：消息以本群自定义前缀开头时，剥离前缀并置唤醒标记，后续按处理后的文本正常匹配指令（如 `#点歌 周杰伦` → 触发点歌插件）。`/setwake` 为**新增模式**，多次设置累积生效。
2. **屏蔽内置命令唤醒**：设置自定义前缀后（开启 `suppress_builtin`），`/` 前缀与 `wake_prefix` 触发的指令唤醒会被屏蔽，仅自定义前缀可触发命令；**@ 提及、@全体、引用回复本机器人等社交性唤醒不受影响**，保留对话能力。
3. **管理指令始终放行**：`/setwake`、`/delwake`、`/wakeprefix` 随时可用，保证能恢复原生唤醒。

关键设计：

- **补丁幂等且只保留一层**：每次安装前沿闭包链剥离历史补丁层并指向当前实例，热重载不会造成旧实例残留。
- **前缀匹配基于消息链原始文本**：即使自定义前缀与 `wake_prefix` 相同（如都是 `#`）也不会误屏蔽。
- **磁盘 JSON 为唯一真相**：不维护内存缓存，`/delwake` 后立即恢复内置唤醒；`/wakereset` 可强制重装拦截层，无需重启进程。

## 排查：`/delwake` 后唤醒没恢复？

管理员发 `/wakestatus` 按顺序排查：

1. **补丁层数** `>1` → 历史残留层，发 `/wakereset` 或重启 AstrBot。
2. **拦截层生效实例 id ≠ 插件实例 id** → 拦截层指向旧实例（热重载残留），发 `/wakereset` 刷新。
3. **数据文件内容**仍含本群前缀 → `/delwake` 未真正写入，可手动删除 `data/plugin_data/astrbot_plugin_group_wake_prefix/group_prefixes.json` 后重启。
4. **`/` 不在 `wake_prefix` 里** → `/xxx` 不响应属正常现象（AstrBot 唤醒完全取决于该配置），与本插件无关。
5. 带参数查询，如 `/wakestatus stats` → 确认指令是否已注册。

**速效解法**：发 `/wakereset` 清空全部自定义前缀并强制重装拦截层，无需重启；若 `/` 已被旧层屏蔽导致发不出，可用尚存的旧前缀（如 `#wakereset`）触发，否则只能重启 AstrBot。

**保底解法**：删除插件，重启 AstrBot

## 已知边界

- 前缀**可以**和系统 `wake_prefix` 相同（如都设 `#`）：v1.2.2 起按消息链原始文本匹配，不会把自己的唤醒也屏蔽掉；此时插件不再重复剥离，指令照常触发。
- `contains` 模式下前缀可能不在句首，插件只负责唤醒、不会剥掉前缀，因此该模式主要用于唤起对话，而非触发指令。要触发指令请使用 `prefix` 模式。
- 前缀剥掉后，模型看到的对话内容里不再带该前缀（如只看到 `点歌 周杰伦` 而非 `#点歌 周杰伦`）。
- 屏蔽内置命令唤醒只在**已设自定义前缀**的群生效；清空前缀后立刻恢复系统默认唤醒。@ 提及与引用回复在任何情况下都不受屏蔽影响。
- **！！！**若添加自定义唤醒词后，原先唤醒词依旧生效，请检查其他唤醒增强等能添加唤醒词的插件配置项。**！！！**
- 仅在群聊中生效；私聊请用系统前缀。
- 需要 AstrBot 版本 >= 4.17.0。
